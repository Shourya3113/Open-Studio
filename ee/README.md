# Open Studio — Enterprise Edition (`ee/`)

This directory contains commercial extensions and enterprise compliance infrastructure for **Open Studio**, licensed under the [Open Studio Commercial License](./LICENSE).

---

## 🏢 Enterprise Features Governed by `ee/`

- **SAML 2.0 / SSO & SCIM Directory Sync**: Enterprise identity provider integration (Okta, Azure AD, Ping).
- **Centralized Model Fleet & On-Prem vLLM Gateways**: Connecting air-gapped developer seats to central GPU clusters.
- **Enterprise Policy Enforcement**: Fleet-wide synchronization of `.openstudio/rules.yaml` (model allow-lists, forbidden file pattern masks, token quotas).
- **SOC 2 Type II Compliance & Audit Aggregator**: Tamper-proof, cryptographically signed audit log exports into enterprise SIEM (Splunk, Datadog).
- **Role-Based Access Control (RBAC)**: Admin, Lead, Developer, and Auditor role hierarchies per workspace.
